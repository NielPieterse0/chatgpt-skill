# Experiment design

Load for a new research question or a material protocol change.

Write a falsifiable hypothesis and the decision it informs. Define target/outcome timing, dataset identity, train/validation/test boundaries, split strategy, feature/preprocessing identity, simplest credible baseline, at least one control for false signal, primary/secondary metrics, uncertainty method, failure criteria, leakage checks, seed/repeat policy, resource budget, stopping criteria, and research promotion criteria before training.

For ordered forecasting define prediction timestamp, target timestamp, horizon, and information cutoff. Do not use future/revised data as historically available. Separate exploratory from confirmatory analysis and do not use the final test set to guide design.
